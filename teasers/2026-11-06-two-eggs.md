## Problem
An Egg breaks only if dropped from above a threshold floor, within a 100-story building. Every time you drop an egg, it is counted as an attempt. You are given 2 eggs to deduce the threshold floor, with a minimum number of attempts in the worst case!

## Solution
**14 drops in the worst case.**

**Why you can't do better.** With the first egg you jump up the building; once it breaks, the second egg must test the floors in the gap one by one, from the bottom. If the first egg is dropped from floor $x_1$ first and breaks, the second egg may need $x_1 - 1$ more drops, so $x_1 \le k$ if you allow $k$ drops in total. If it survives, you have one drop fewer left, so the next jump can be at most $k - 1$ floors higher, then $k - 2$, and so on. With $k$ drops you can cover at most
$$
k + (k-1) + \dots + 1 = \frac{k(k+1)}{2}
$$
floors. For 100 floors that needs $\frac{k(k+1)}{2} \ge 100$, so $k \ge 14$ (13 drops only cover 91 floors).

**How to do it in 14.** Drop the first egg from floors 14, 27, 39, 50, 60, 69, 77, 84, 90, 95, 99, 100 (each jump one smaller than the last). When it breaks, walk the second egg up through the floors in between. Every path uses at most 14 drops: breaking at 14 costs 1 + 13, breaking at 27 costs 2 + 12, and so on.
