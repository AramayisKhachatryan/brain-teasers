# Brain Teasers

Daily brain teasers for Aramayis and Armen, with a running score.
Live at **https://aramayiskhachatryan.github.io/brain-teasers/**. On an iPhone, open it in Safari and use
Share → Add to Home Screen.

Teasers are markdown files in [`teasers/`](teasers/); see [`teasers/README.md`](teasers/README.md) for the format.
How the app is built and deployed is in [`CLAUDE.md`](CLAUDE.md).
